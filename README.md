# 온도를 지켜라 · 에코커넥트 과학 탐구실

초등 5·6학년군을 위한 단열 탐구 웹앱입니다.

## 기능
- 단열층과 뚜껑을 바꿔 따뜻한 물·차가운 물의 온도 변화 비교
- 실제 온도계 측정값 입력과 그래프 비교
- 예상·실험 결과·설명으로 탐구 카드 작성 및 인쇄
- 기기별 체험 기록 저장 및 CSV 내보내기

## 교육과정
2022 개정 과학과 교육과정: [6과07-03], [6과07-04], [6과08-03].

## 모형과 데이터
가상 실험은 학습용 단순 모형입니다. 실제 재료의 성능이나 탄소 감축량을 예측하지 않습니다.
이름·연락처를 입력받지 않으며, 체험 기록은 각 브라우저의 localStorage에만 저장됩니다.
다른 기기의 기록은 자동으로 합쳐지지 않습니다. 브라우저 데이터를 삭제하면 기록도 삭제됩니다.
GitHub 저장소에는 체험 기록이 포함되어 있지 않습니다.

## 실행
빌드 과정 없이 정적 웹 서버에서 실행할 수 있습니다.
GitHub Pages는 main 브랜치의 루트(/) 폴더를 게시하도록 설정합니다.
